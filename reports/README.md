# Anonymized Report Examples

This folder contains anonymized report examples for layout and output reference.

Included examples:

- `PET-Writing-Report-Student-A-Computer-Games.pdf`: actual printable PDF report example
- `PET-Writing-Report-Student-A-Computer-Games.html`: source HTML report example

Do not commit real student reports here unless names, dates, writing content, and local file paths have been reviewed and anonymized.
