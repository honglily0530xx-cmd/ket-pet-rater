# KP Writing Lab 中文使用指南

KP Writing Lab 是一个给英语老师使用的本地写作评分工具，适合 KET / PET 写作批改、反馈报告生成和学生写作成长记录。

## 它能解决什么问题

- 每次批改后，生成结构统一的写作反馈报告。
- 按 KET / PET 写作维度整理评分与建议。
- 把历史 PDF 报告导入后，形成学生看板。
- 查看班级平均分、风险学生、学生个人历史记录。
- 本地保存数据，避免把学生资料直接交给第三方平台管理。

最核心的痛点是：把“原始作文”变成一份结构统一、可打印、可存档的标准化写作测评报告。

## 适合谁用

- KET / PET 英语老师
- 小班课或一对一老师
- 需要长期跟踪学生写作进步的老师
- 想用 AI 辅助批改，但又希望保留自己批改框架的老师

## 安装和启动

先确认电脑已经安装 Node.js 18 或以上版本。

```bash
git clone https://github.com/honglily0530xx-cmd/ket-pet-rater.git
cd ket-pet-rater
npm start
```

启动后打开：

```text
http://127.0.0.1:3000
```

第一次使用时，在左侧注册一个本地账号，然后登录。

## 不配置 API Key 可以用吗

可以。

不配置模型密钥时，系统会返回一个本地预览版报告，用于测试流程和界面。

如果要生成完整 AI 评分报告，需要配置模型 API Key。

## 配置 OpenAI

```bash
export OPENAI_API_KEY="你的 API Key"
export OPENAI_MODEL="gpt-4.1-mini"
npm start
```

## 基本使用流程

1. 登录账号。
2. 在“写作评分”里填写学生编号、考试等级、体裁、题目和作文原文。
3. 点击“生成评分报告并存档”。
4. 在右侧预览报告。
5. 下载 HTML，或在新窗口打开后打印为 PDF。
6. 到“评分存档”里查看历史生成记录。
7. 到“学生看板”里导入历史 PDF 报告，查看班级和学生分析。

## 使用 Skill 后的变化

这个项目的核心变化，不只是“输入一篇作文，让 AI 改一下”，而是把零散的作文批改过程整理成一个稳定的测评流程。

### 使用前

老师通常需要手动完成：

- 判断学生写作体裁和任务要求
- 找出语法、词汇、结构问题
- 给每个错误写解释
- 按 KET / PET 评分维度估分
- 写一版优化范文
- 整理成适合发给学生或家长的报告
- 手动保存文件和记录分数

这些步骤容易每次格式不同，也不方便长期追踪学生进步。

### 输入什么

使用 Skill 时，老师只需要提供核心输入：

| 输入项 | 示例 | 作用 |
|---|---|---|
| 考试等级 | `KET` / `PET` | 决定评分标准和目标难度 |
| 写作体裁 | `article` / `email` / `story` / `review` / `message` | 决定文体分析方式 |
| 作文题目 | 题目原文或任务要求 | 判断学生是否回应任务点 |
| 学生编号 | `Student A` | 用于报告标题和存档 |
| 学生原文 | 学生作文全文 | 作为批改和优化的基础 |
| 目标档位 | `PET Band 5` / `B2` | 决定优化范文的语言高度 |
| 布局模式 | `A` / `B` | 决定报告中原文、标错和解释的排版 |

### Skill 做了什么

Skill 会把输入内容标准化为一个测评对象，然后按固定流程处理：

1. 识别考试等级、体裁、题目、学生编号和作文原文。
2. 估算学生作文字数。
3. 按出现顺序给关键错误编号。
4. 为每个错误生成中文解释和自然英文修改。
5. 按 Content、Communicative Achievement、Organisation、Language 四个维度给出评分理由。
6. 基于学生原文生成一版更高质量的优化范文。
7. 把所有内容排版成可打印的 HTML 报告。
8. 登录状态下自动保存到评分存档。

### 得到什么

最终输出是一份标准化写作测评报告，通常包含：

- 报告标题、学生编号、体裁、主题和字数
- 带编号批注的学生原文
- 错误解释表
- 优化范文
- 修改亮点说明
- 官方风格四维评分
- 总分 `/20`
- Cambridge English Scale 估算
- CEFR 等级判断
- 可下载 HTML，或打印成 PDF

### 转化链路

```text
老师输入：
考试等级 + 体裁 + 题目 + 学生编号 + 学生原文

        ↓

Skill 处理：
识别任务 → 标出错误 → 解释问题 → 优化表达 → 四维评分 → 生成报告

        ↓

老师得到：
一份结构统一、可打印、可存档、可复盘的 KET / PET 写作测评报告
```

### 一个最小输入示例

```text
考试等级：PET
体裁：Article
学生编号：Student A
题目：Write an article about the advantages and disadvantages of computer games.
学生原文：
Nowadays, computer games has played an important role in teenagers' free time...
```

生成后，报告会把 `computer games has` 这类问题直接在原文中编号标出，并在旁边解释表里说明为什么要改，给出更自然的表达，例如 `computer games play` 或根据句意改写句子。

## 建议的学生命名方式

公开演示或分享时，不建议使用真实姓名。

推荐使用：

- `Student A`
- `Student B`
- `Class A - Student 01`
- `PET-2026-Student-01`

## 历史报告导入

如果你已经有一批 PDF 写作报告，可以在“学生看板”里导入。

导入后可以查看：

- 班级均分
- CES 均值
- 分数分布
- 风险名单
- 学生历史记录
- 单个学生的报告详情

## 隐私提醒

不要把真实学生姓名、作文原文、完整 PDF 报告直接上传到公开 GitHub 仓库。

本项目会忽略本地数据库和临时文件，但你仍然需要检查自己新增的示例文件是否已经匿名化。
