# 标准化报告输出示例

这个项目真正解决的痛点是：老师不只是想“让 AI 改一篇作文”，而是想把学生作文稳定地变成一份可以发给学生、家长或用于课堂讲评的标准化写作测评报告。

示例报告：

[PET Writing 标准化报告示例](../reports/PET-Writing-Report-Student-A-Computer-Games.html)

## 从输入到报告

### 老师输入

```text
考试等级：PET
体裁：Article
学生编号：Student A
题目：Write an article about the advantages and disadvantages of computer games.

学生原文：
Nowadays, computer games has played an important role in teenagers' free time.
First of all, my friends and I are absolutely interested in playing computer games...
```

### Skill 输出

系统不会只返回几句笼统评价，而是生成一份结构统一的 HTML 写作测评报告。

报告可以：

- 在浏览器中预览
- 下载为 HTML
- 打印为 PDF
- 作为学生写作档案保存
- 后续导入学生看板做长期分析

## 报告结构

标准化报告通常包含以下模块。

### 1. 报告基本信息

报告顶部会统一显示：

- 考试等级
- 写作体裁
- 学生编号
- 主题
- 估算字数
- 建议写作时长
- 整体水平判断

示例：

```text
PET Writing 报告 — Student A · Computer Games
学生：Student A
字数：约 170 词
任务类型：Article
主题：Computer games 的利与弊
整体水平：接近 B2 段
```

### 2. 学生原文与编号批注

报告会保留学生原文，并把关键问题按出现顺序编号。

示例：

```text
Nowadays, computer games has [1] played an important role...
... forget the difficulties and troubles of learning during playing [2] computer games.
```

这样课堂讲评时，老师可以直接说“看第 1 个问题”“第 2 个问题是什么”，学生也更容易对应原文。

### 3. 错误解释表

每个编号都会对应一个解释，而不是只给正确答案。

示例：

| 编号 | 报告中的解释 |
|---|---|
| 1 | `computer games has -> computer games play`：主语复数，动词用复数形式。 |
| 2 | `during playing -> while playing`：表示“在……时候”更自然。 |
| 3 | `it also let us -> it also lets us`：一般现在时第三人称单数加 `-s`。 |

这个模块解决的是“学生知道错在哪里，也知道为什么错”。

### 4. 优化范文

报告会基于学生原文生成一版更高质量的范文。

重点不是完全重写，而是保留学生原有观点和结构，再提升表达。

示例变化：

```text
原表达：
we might get caught in them and escape from reality

优化后：
we might get addicted to them and try to escape from reality
```

### 5. 修改亮点说明

报告会说明优化后的变化，而不是只给一篇范文。

通常覆盖：

- 内容是否更完整
- 结构是否更清楚
- 衔接是否更自然
- 词汇是否更准确
- 文体是否更适合考试要求

### 6. 官方风格四维评分

报告会按 KET / PET 写作常用评分维度整理评价：

| 维度 | 说明 |
|---|---|
| Content | 是否完成题目任务 |
| Communicative Achievement | 是否符合文体和读者需求 |
| Organisation | 段落、逻辑和衔接 |
| Language | 词汇、语法、准确性和范围 |

输出中会有：

- 每项分数
- 简短评分理由
- 总分 `/20`
- Cambridge English Scale 估算
- CEFR 等级判断

### 7. 可交付格式

最终报告是一个完整 HTML 文件，可以直接：

- 发给学生
- 打印成 PDF
- 存入课程档案
- 作为学生阶段性写作记录

## 为什么这比普通 AI 批改更有用

普通 AI 批改常见问题是：

- 每次输出格式不一致
- 错误解释深浅不稳定
- 没有固定评分结构
- 不方便打印
- 不方便长期存档
- 不方便和历史记录比较

KP Writing Lab 的目标是把输出稳定下来：

```text
原始作文
  -> 编号批注
  -> 错误解释
  -> 优化范文
  -> 四维评分
  -> 标准化 HTML/PDF 报告
  -> 存档与看板分析
```

核心价值是：让老师每次都能得到一份结构一致、可复用、可交付的写作测评报告。
